# ไทยไปจีน · Thai Pai Jean

ไกด์คุนหมิง–ต้าหลี่ 11–16 ธันวาคม 2026 สำหรับมือถือ ภาษาไทย ออกแบบเป็นสมุดเดินทาง มีตาราง 6 วัน จุดถ่ายตามแสง แผนผังสำรอง My Maps ของผู้เดินทาง ชื่อจีนคัดลอกได้ ชุดกล้อง OM-1 งบ และรายการเตรียมตัว

## GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดใน repository นี้ขึ้นสาขา `main` (รวม `.github/workflows/pages.yml`)
2. เปิด Settings → Pages → Source → GitHub Actions
3. การ push ไป main จะตรวจไฟล์และเผยแพร่โฟลเดอร์ `site/` โดยอัตโนมัติ
4. URL ที่คาดหมายเมื่อ deploy สำเร็จ: https://jedt3d.github.io/thai-pai-jean/

ทางเลือกที่ไม่ต้องใช้ workflow: Settings → Pages → Deploy from a branch → main → /(root) แล้ว Save หน้าแรกจะส่งต่อไป site/ อัตโนมัติ ไม่ต้องทำสำเนา

## ทดสอบในเครื่อง

```sh
python3 scripts/check_site.py
python3 -m http.server 8080 --directory site
```

เปิด http://localhost:8080 ไม่มี dependencies และไม่ต้อง build

## ข้อมูลและการใช้งาน

- `site/data.js` ตารางและสถานที่; `site/index.html` เนื้อหาบทอื่น ๆ
- แผนที่ Google โหลดเมื่อผู้ใช้กดเท่านั้น และอาจถูกจำกัดในจีน มีแผนผัง SVG ใช้ได้โดยไม่โหลดภายนอก
- แผนที่ My Maps: https://www.google.com/maps/d/viewer?mid=1lE7UFUHc2npUgthw_yn-MtbtvPUCnrU
- หมุดบางจุดอ้างอิงเพียงบริเวณ ต้องยืนยันที่จอดและทางเข้า โรงแรม/ตั๋วยังไม่ได้จอง ราคาเป็นงบประมาณ
- ภาพหน้าปกเป็นภาพประกอบ SVG ไม่ใช่ภาพถ่าย และไม่รับประกันทัศนียภาพ
- รายการติ๊ก ขนาดตัวอักษร และจุดโปรดใช้ localStorage ในเครื่องผู้ใช้
- Service worker เก็บไฟล์ไกด์ออฟไลน์หลังเปิดผ่าน HTTPS สำเร็จ ไม่เก็บแผนที่ Google หรือเว็บภายนอก
- เว็บไซต์นี้เป็นสาธารณะ อย่าใส่เลขพาสปอร์ต ข้อมูลติดต่อส่วนตัว หรือข้อมูลการจองที่เป็นความลับ

แหล่งข้อมูลอยู่ท้ายเว็บไซต์และ `site/guide-th.md` ตรวจค้น 29 ตุลาคม 2026

## ชื่อสถานที่ ภาพ และแบบอักษร

ชื่อสถานที่ใช้จีนตัวย่อ / พินอิน / ไทย ในตาราง แผนที่ รายการชื่อ และไฟล์ดาวน์โหลด ภาพอ้างอิงจริงจาก Wikimedia Commons พร้อมเครดิต/ลิงก์สัญญาอนุญาต ดู `CREDITS.md` สำหรับที่มาและข้อจำกัดของแต่ละภาพ

โฮสต์ IBM Plex ภายในเว็บ: Sans Thai Looped สำหรับเนื้อหา, Sans Thai สำหรับหัวข้อ, Sans สำหรับ Latin/Pinyin และ Sans SC สำหรับจีน แบบอักษรและภาพรวมประมาณ 5.7 MB และรวมอยู่ในแคชออฟไลน์ ไม่ใช้บริการฟอนต์ภายนอกขณะอ่าน
